# 🎨 12 Distinct Aesthetic Archetypes Matrix

When revamping UI, avoid generic templates by intentionally applying one of these 12 proven archetypes based on product domain:

---

| Archetype | Best For Domains | Primary Typography | Color Palette Formula | Radii & Borders | Key Signature Move |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **1. Industrial Technical** | DevTools, Infra, Observability, APIs | *Space Grotesk + JetBrains Mono* | Slate-950 background, Amber-500 or Emerald-500 accent, hairline slate-800 borders | `rounded-none` or `rounded-xs` (2px), 1px crisp borders | Live code terminal preview, density toggle, telemetry badge |
| **2. Swiss International** | SaaS, FinTech, Analytics, Enterprise | *Neue Haas / Helvetica / Geist + Inter* | Stark White / Black, single vibrant Cobalt Blue (`#2563eb`) accent | `rounded-sm` (4px), rigid column grid | Asymmetric grid alignments, huge numbered data callouts |
| **3. Warm Editorial** | Content, Publishing, Creative, AI Writer | *Fraunces / Playfair + Plus Jakarta Sans* | Cream/Sand `#fcfbf7`, Terracotta `#c2410c`, Deep Forest Green `#14532d` | `rounded-md` (6px), soft muted dividers | Drop-caps, elegant serif quotes, wide margins, relaxed leading |
| **4. Technical Neobrutalism** | Web3, Creator Tools, Agency, Portfolios | *Syne / Archivo Black + Work Sans* | High-contrast Pale Yellow `#fef08a`, Lilac `#e9d5ff`, Pitch Black `#000` | `rounded-md` (8px), 2px-3px solid black border with hard drop-shadow `shadow-[4px_4px_0_0_#000]` | High-impact sticker badges, punchy contrasting buttons |
| **5. Deep OLED Cyber** | Gaming, Security, Trading, Audio Apps | *Orbitron / Rajdhani + Geist Mono* | Pure OLED `#000000` & `#09090b`, Electric Neon Cyan `#06b6d4` & Lime `#84cc16` | `rounded-sm` (3px), subtle border glow | Realtime sparklines, glowing edge highlights, dark HUD panels |
| **6. Minimalist Luxury** | E-commerce, Real Estate, Fashion, Travel | *Cinzel / Bodoni + DM Sans* | Warm Charcoal `#18181b`, Champagne Gold `#d4af37`, Soft Alabaster `#f9fafb` | `rounded-lg` (8px), ultra-thin 0.5px border | Full-bleed photography, subtle opacity hover transitions, generous whitespace |
| **7. Clean Modern Nordic** | Productivity, Note-Taking, Project Mgmt | *Outfit + Inter* | Pure White, Soft Sky Blue `#0284c7`, Warm Gray `#f3f4f6` | `rounded-xl` (12px), smooth subtle shadow `shadow-sm` | Segmented pill tab controls, subtle icon tint backgrounds |
| **8. Bento Data Matrix** | Dashboard, Crypto Portfolio, AI Agents | *Plus Jakarta Sans + Geist Mono* | Dark Zinc `#18181b`, Vivid Violet Accent `#8b5cf6` or Emerald `#10b981` | `rounded-xl` (14px), 1px border `border-zinc-800` | Bento cards spanning 1x1, 2x1, and 2x2 with live graph widgets |
| **9. Retro Terminal CLI** | Hacker Tools, Package Registries, Utilities | *IBM Plex Mono / Fira Code* | Matrix Dark Green `#052e16` or Amber CRT `#451a03` | `rounded-none`, 1px dashed borders | ASCII art headers, blinking block cursor, keybinding hints |
| **10. Glass Precision (Craft)** | macOS Native Apps, Audio Plugins, Visualizer | *SF Pro / Inter Display + SF Mono* | Deep Translucent Glass `#18181b/80`, Fine Inset Shadow `shadow-inner` | `rounded-2xl` (16px), fine border `border-white/10` | Inset hardware knobs, metallic gradient switches, subtle noise texture |
| **11. High-Density Financial** | Trading Desks, Accounting, Inventory | *Geist Mono + Roboto Condensed* | Dense Dark Slate `#0f172a`, Profit Green `#22c55e`, Loss Crimson `#ef4444` | `rounded-none`, compact 0px padding grids | Monospaced numeric tables with tabular figures, ticker ribbons |
| **12. Bold Typography Poster** | Landing Page, Conference, Music, Brand | *Clash Display / Syne + Cabinet Grotesk* | High-voltage Orange `#ea580c` on Deep Navy `#020617` | `rounded-lg` (8px), giant font scale (96px+) | Overlapping text headers, ticker marquee, dynamic kinetic hover |
