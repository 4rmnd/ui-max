## 🌟 Mengapa UI MAX?

Kebanyakan antarmuka yang dibuat oleh AI tampak **seragam, hambar, dan klise** (*AI Slop*):
* ❌ Gradien ungu/indigo template (`from-purple-500 to-indigo-500`)
* ❌ Kotak mengambang dengan blur sabun berlebihan (`backdrop-blur-md bg-white/10`)
* ❌ Tipografi membosankan mengandalkan default *Inter* tanpa kontras
* ❌ Grid 3-kolom kaku tanpa hierarki data
* ❌ Kalimat pemasaran klise (*"Unleash the power of AI..."*)

**UI MAX** mengubah cara AI membuat UI dengan menyatukan **7 God-Tier Engineering Engines**, **75 Brand Design DNAs**, **20 Skills Terkurasi**, dan **Parallel Subagent Fleet** untuk menghasilkan antarmuka kelas dunia berstandar enterprise.

---

## ⚡ The 7 God-Tier UI MAX Engines (God-Mode v3.0)

1. 🧠 **Perception-Engine (OKLCH Wide-Gamut P3)**: Menggunakan fisika warna perceptually uniform `oklch()`, dynamic relative syntax, dan kontras WCAG AAA (≥ 7:1).
2. 📐 **Spatial-Kinetic Engine**: Mengganti breakpoint kaku dengan fluid mathematical `clamp()` typography & 4px baseline rhythm.
3. 💫 **Tactile Micro-Physics Shaders**: Transisi spring natural `cubic-bezier(0.16, 1, 0.3, 1)`, tactile `active:scale-[0.98]`, dan inset hardware highlights.
4. 🧬 **Brand DNA Hologram**: 75 Matriks token desain dari brand legendaris (`Linear`, `Stripe`, `Apple`, `Raycast`, `Supabase`, dll.).
5. ✍️ **Cognitive De-Slop Engine**: Menghapus 100% copy robotik AI dan mengubahnya menjadi *active human voice* yang berbobot.
6. 👥 **Autonomous Parallel Subagent Fleet**: 5 worker subagent spesialis yang berjalan bersamaan (*concurrency*).
7. 🛡️ **Self-Healing AST Transformer**: Mendeteksi dan memperbaiki 40+ kelemahan desain secara otomatis.

## 🚀 Cara Penggunaan Singkat

### 1. Jalankan God-Mode Synthesizer (Terminal)
```bash
npm run god-mode
# atau dengan Brand DNA: node scripts/ui-max-god-mode.js --dna linear
```

### 2. Prasyarat & Pengecekan Lingkungan (Cuma 10 Detik)
```bash
npm run setup
```

### 3. Mulai Pakai di Google Antigravity IDE
Cukup ketik di chat:
> *"UI MAX, perbaiki UI halaman ini dengan style Linear"* atau *"UI MAX deslop dashboard ini"*

### 4. Di Claude Code CLI
```bash
/ui-max
```

### 5. Jalankan Linter Scanner via Terminal
```bash
npm run scan
```

## 👥 Parallel Subagent Architecture (Multi-Task Concurrency)

Untuk proyek skala besar (banyak komponen / multi-page), **Lead UI Architect** otomatis men-dispatch **5 Subagent Spesialis** yang bekerja secara paralel tanpa saling menghambat:

| Worker Subagent | Tugas Paralel | Benefit |
| :--- | :--- | :--- |
| **`subagent-ui-auditor`** | Memindai puluhan file kode sekaligus mencari 40+ AI tells | Audit instan tanpa jeda |
| **`subagent-browser-qa`** | Buka headless browser via `chrome-devtools` MCP & ambil screenshot | Validasi visual live |
| **`subagent-copy-editor`** | De-slop semua copy & teks menjadi *active voice* (`stop-slop`) | Teks tajam & berbobot |
| **`subagent-component-builder`** | Membangun section (Hero, Bento, Pricing, Footer) terpisah | Pengerjaan kode jauh lebih cepat |
| **`subagent-a11y-polish`** | Menghitung kontras WCAG AAA & focus ring keyboard | Kualitas standar enterprise |

## 📦 Daftar Lengkap 19 Skills (`.agents/skills/`)

1. **`anti-slop-ui`**: **[MASTER AUTONOMOUS AGENT]** Eksekusi mandiri perbaikan UI menyeluruh.
2. **`browser-fallback-inspector`**: Fallback otomatis ke live browser (chrome-devtools) saat scraping statis gagal.
3. **`skill-creator`**: Pembuatan, pengujian, dan benchmarking AI agent skills.
4. **`shadcn`**: Integrasi komponen resmi shadcn/ui & registri discovery.
5. **`stop-slop`**: Menghapus pola kalimat klise AI pada copy & teks.
6. **`avoid-ai-design`**: Deteksi dan rewrite pola generic AI design.
7. **`clone-website`**: Kloning dan reverse engineering website menjadi Next.js/Tailwind.
8. **`grill-with-docs`**: Interview arsitektur terstruktur & update ADR / CONTEXT.md.
9. **`improve`**: Auditor codebase penyusun rencana perbaikan terstruktur.
10. **`migrate-radix-to-base`**: Panduan migrasi Radix UI ke Base UI.
11. **`frontend-design`**: Identitas visual unik & tipografi berani.
12. **`ui-ux-pro-max`**: Sistem desain komprehensif, 161 palet warna, 50+ gaya.
13. **`taste-skill`**: Standar taste estetika dan craftsmanship tinggi.
14. **`interface-design`**: Desain token, hierarki komponen, dan state interaktif.
15. **`refactoring-ui`**: Refactoring visual praktis (kontras, hierarki, spasi).
16. **`hallmark`**: Standar visual polish industri.
17. **`impeccable`**: Presisi layout pixel-perfect.
18. **`designer-process`**: Alur perancangan desain konsep ke kode.
19. **`styleseed`**: Eksplorasi gaya desain & variasi tema.
